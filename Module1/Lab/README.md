# Lab instruction

## Step 1

First, create a prompt to explain something you'd like to understand better, using a metaphor or analogy related to something you already know. For example, if you know a lot about coffee, you could have GPT 3.5 "Explain how sleep works using a metaphor or analogy related to coffee."

Go ahead and start with this prompt: 

```
"Explain how sleep works using a metaphor or analogy related to coffee."
```

Type the prompt above into the message bar at the bottom and press the upward-facing arrow to the right to send it.

When you are done, adapt the prompt to explore a new concept using metaphors and analogies from a domain that you know well. 

For example, you might change the prompt to:

```
"Explain the brain's default mode network using a metaphor or analogy related to BMX bicycle racing."
```

The basic pattern is:
```
"Explain[Insert a topic] using a metaphor or analogy related to [Insert a domain]."
```

Customize the topic and domain to see how well it explains things. Choose some topics that you know a lot about to see what it gets right--and where it can use improvement.

When you are done with your exploration, press the "New chat" button in the upper left corner to start a new conversation.

## Step 2
Now, you are going to tell GPT-3.5 about you and let it select the metaphors and analogies to use. 

Create a prompt using this format:
```
"About Me:

----------

[Insert 1-2 paragraphs about you, your interests, and things you know about]

----------

Explain [Insert a topic of your choice] using metaphors and analogies that will resonate with me."
```
Make sure and fill in the [placeholders] with the indicated text. 

For example, I (Jules), know a lot about software engineering, cybersecurity, painting with acrylic paint, and wheel throwing ceramics. I might fill in the prompt as:
```
"About Me:

----------

I am a Professor of Computer Science at Vanderbilt University. I teach Software Engineering and Cybersecurity. I paint with acrylic paint on canvas and paper. I love combining wheel throwing and hand building to make ceramic art.

----------

Explain the Krebs Cycle to me using metaphors and analogies that will resonate with me."
```
Experiment with telling GPT-3.5 different things about you. How does it affect the metaphors and analogies that get used? When you have found a prompt that gives you great explanations, save it! It is your personal Metaphor Pattern prompt.
